# NetShift

Приложение для Windows, которое помогает переключать DNS и управлять [zapret от Flowseal](https://github.com/Flowseal/zapret-discord-youtube).

## Скачать и установить

Скачайте **NetShift.exe** из [последнего релиза](https://github.com/rkfsociety/NetShift/releases/latest) и запустите. Приложение установится в профиль пользователя, создаст ярлык на рабочем столе и установит DNS-службу. Для системных изменений Windows запросит подтверждение администратора.

Требуется Windows 10 или 11. Устанавливать .NET отдельно не нужно.

## DNS

Во вкладке **DNS** выберите сетевой адаптер и DNS-провайдера, затем нажмите **Применить DNS**. Чтобы вернуть настройки Windows, выберите **Вернуть DHCP**. Можно также указать собственные IPv4/IPv6 адреса и включить DoH.

Доступны Cloudflare, Google, Quad9, AdGuard, Comss.one, Xbox DNS, DNS-AI и пользовательские адреса. Настройки DNS сохраняются в Windows и продолжают работать после закрытия приложения. DNS-служба запускается вместе с Windows независимо от запуска NetShift.

## zapret

Во вкладке **zapret** скачайте последний пакет, выберите стратегию и запустите её. NetShift получает пакет из официального GitHub-релиза Flowseal и проверяет архив перед установкой. Здесь же можно настроить службу zapret, которая запускается вместе с Windows.

Закрытие окна скрывает приложение в системный трей. Чтобы завершить работу интерфейса, выберите **Выход** в меню значка NetShift. DNS и запущенный zapret при этом продолжают работать.

NetShift проверяет обновления при запуске. Установить доступную версию можно кнопкой **Проверить обновления**.
