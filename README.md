# NetShift

Нативное приложение для Windows для переключения DNS и управления официальным пакетом [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

## Возможности

- Просмотр сетевых адаптеров и текущих DNS-серверов.
- Выбор DNS-провайдера или своих IPv4/IPv6 адресов, применение DNS и возврат на DHCP. Настройки DNS-AI обновляются с его сайта; при выборе DNS-AI можно применить системный DoH без отката на открытый DNS.
- В списке провайдеров есть Comss.one: DNS-адреса и DoH-шаблон для Windows из [официальной инструкции](https://www.comss.ru/page.php?id=7315).
- В списке провайдеров есть Xbox DNS с IPv4/IPv6 адресами и DoH-шаблоном из [официальной инструкции](https://xbox-dns.ru/).
- Настроенный DNS хранится в Windows и не зависит от открытого окна NetShift; обновление приложения его не сбрасывает.
- Отдельная служба NetShift DNS запускается автоматически вместе с Windows, независимо от приложения, и восстанавливает выбранный профиль DNS после перезагрузки. Установить или удалить службу можно во вкладке DNS.
- Релизный `NetShift.exe` при первом запуске устанавливает приложение в `%LOCALAPPDATA%\Programs\NetShift`, создаёт ярлык на рабочем столе и в меню «Пуск» на установленную копию и устанавливает встроенную DNS-службу после подтверждения UAC.
- Переключатель в заголовке включает и выключает автозапуск интерфейса NetShift при входе пользователя в Windows; настройка службы DNS от него не зависит.
- Проверка последнего GitHub-релиза, загрузка ZIP-архива zapret и сверка SHA-256 по GitHub API.
- Распаковка проверенного релиза в `C:\NetShift\zapret-<версия>` с проверкой путей архива.
- Запуск выбранной стратегии, установка автозапускающейся службы zapret и её удаление.
- Настройка игрового TCP/UDP фильтра, режима IPSet и проверки последнего релиза перед запуском стратегии.
- Загрузка IPSet и hosts-файла с официального репозитория. Перед изменением системного hosts приложение показывает новые записи и создаёт резервную копию, которую можно восстановить из приложения.
- Замена активных UDP fake-файлов, диагностика системы в режиме чтения и запуск официального тестового скрипта.
- Автоматическая проверка новой версии NetShift при запуске и установка GitHub-релиза с SHA-256 проверкой.
- Закрытие окна скрывает NetShift в системный трей; команда «Выход» завершает интерфейс, не сбрасывая DNS Windows и не останавливая zapret.

Права администратора запрашиваются только для системных изменений. Диагностика ничего не меняет. Тестовый скрипт запускается отдельно в PowerShell по явному действию пользователя; он может временно менять IPSet и останавливать/перезапускать `winws.exe`.

Настройки DNS-AI автоматически загружаются с [официальной страницы настройки](https://dns-ai.ru/#setup) при запуске приложения и доступны для ручного обновления. Если сайт недоступен или изменил разметку, используются встроенные резервные адреса. Включение системного DoH зависит от поддержки команд DNS Client в установленной версии Windows.

## Требования

- Windows 10 или 11.
- .NET 10 SDK для сборки.

## Сборка и запуск

```powershell
dotnet build .\src\NetShift.App\NetShift.App.csproj -c Release
dotnet run --project .\src\NetShift.App\NetShift.App.csproj
dotnet publish .\src\NetShift.DnsService\DnsService.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Выпуск и обновление NetShift

Публикация тега `vMAJOR.MINOR.PATCH` запускает [.github/workflows/release.yml](.github/workflows/release.yml). Workflow собирает самодостаточное приложение `NetShift.exe` для `win-x64` со встроенной DNS-службой. В GitHub Release выкладываются запускаемый EXE и его SHA-256, а также ZIP-архив с EXE и SHA-256 для автообновления уже установленного приложения. После публикации workflow удаляет предыдущие релизы и все старые версионные теги `vMAJOR.MINOR.PATCH`, оставляя только текущую версию.

Релизная сборка знает адрес своего GitHub-репозитория и проверяет последний стабильный релиз при запуске. Если версия новее, NetShift предлагает скачать и установить её. Перед установкой приложение сверяет ZIP с SHA-256 из релиза, затем заменяет установленный EXE и запускает обновлённую версию. Локальные сборки без метаданных GitHub показывают, что проверка доступна в опубликованных релизах.

При первом запуске загруженный из релиза `NetShift.exe` копирует себя в папку пользователя и запускает установленную копию. Ярлык на рабочем столе всегда ведёт в `%LOCALAPPDATA%\Programs\NetShift\NetShift.exe`, а не на скачанный файл. Системная DNS-служба устанавливается в `%ProgramFiles%\NetShift\DnsService` и запускается вместе с Windows независимо от интерфейса NetShift.

## Работа с zapret

NetShift получает метаданные релиза с GitHub API Flowseal, выбирает ZIP-архив релиза и сверяет его SHA-256 с digest из ответа API. Затем архив распаковывается в папку на системном диске. Сами скрипты и бинарные файлы zapret в проект NetShift не включены.

Стратегии остаются скриптами официального пакета. NetShift запускает выбранный `general*.bat`; установка службы настраивает Windows-службу `zapret` с параметрами выбранной стратегии. Перед установкой, удалением службы и изменением hosts приложение показывает подтверждение.

Пакет содержит WinDivert со своими условиями лицензирования и может вызвать предупреждения антивируса. Проверяйте состав и лицензии в [официальном репозитории](https://github.com/Flowseal/zapret-discord-youtube) и в конкретном релизе, который устанавливаете.
