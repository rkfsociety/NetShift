# Память проекта

- Подтверждено: долговременные правила и знания Codex для NetShift хранятся в `.codex/` и коммитятся вместе с проектом. `rules.md` содержит постоянные инструкции, `memory.md` — проверенные факты; общие инструкции `AGENTS.md` сюда не копируются.
- Подтверждено: версия выпуска приложения задаётся в `src/NetShift.App/NetShift.App.csproj`. Workflow `.github/workflows/release.yml` использует её для выпуска, когда она новее существующих тегов `vMAJOR.MINOR.PATCH`.
- Подтверждено: версия DNS-службы задаётся отдельно в `src/NetShift.DnsService/DnsService.csproj`; изменения версии службы не следуют автоматически из изменений приложения.
